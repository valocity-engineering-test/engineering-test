## 🔍 Quick Look

### **Original UpdateQuality() Method:**
```csharp
public void UpdateQuality()
{
	for (var i = 0; i < Items.Count; i++)
	{
		if (Items[i].Name != "Aged Brie" && 
			Items[i].Name != "Backstage passes...")
		{
			if (Items[i].Quality > 0)
			{
				if (Items[i].Name != "Sulfuras...")
				{
					if (Items[i].Name == "Conjured...")
					{
						Items[i].Quality = Items[i].Quality - 2;
					}
					else
					{
						Items[i].Quality = Items[i].Quality - 1;
					}
				}
			}
		}
		// ... 50+ more lines of nested ifs ...
	}
}
```

### **Refactored UpdateQuality() Method:**
```csharp
public void UpdateQuality()
{
	for (var i = 0; i < Items.Count; i++)
	{
		var itemUpdater = ItemUpdaterFactory.CreateUpdater(Items[i]);
		itemUpdater.Update(Items[i]);
	}
}
```

## 🎓 Design Patterns Used

### **Strategy Pattern**
- Each item type has its own update strategy
- Strategies selected at runtime
- New strategies easy to add

### **Factory Pattern**
- ItemUpdaterFactory creates appropriate updater
- Centralized creation logic
- Easy to modify item type mapping

### **Dependency Injection Ready**
- IItemUpdater interface enables DI
- Easy to mock for testing
- Loose coupling throughout
